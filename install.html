OpenFront x50 스크립트 설치

v4.2.2 · 커서 위치의 수소 혼합 / 원자 집중 공격을 비교하고, 발사 중 방어 변화에 대응합니다.
I: 선택한 위치를 재검증한 후 추천 계획 실행 · Esc: 남은 발사 취소 · F8: 사일로·SAM 배치 상세
사설·연습 로비용. 표시 결과는 현재 상태를 바탕으로 한 예측입니다.

  1. Tampermonkey 설치 (먼저!)

    크롬 웹스토어에서 Chrome에 추가 → 확장 프로그램 추가 를 누르세요.

    Tampermonkey 설치 페이지 열기

    설치 후 한 번 더: chrome://extensions → Tampermonkey → 세부정보 → 사용자 스크립트 허용 켜기
    (이걸 빼먹으면 스크립트가 작동하지 않습니다)

  2. 스크립트 설치

    Tampermonkey가 설치된 뒤에 아래 버튼을 누르면 Tampermonkey 설치 화면이 뜹니다 → 설치 클릭.

    스크립트 설치 (Tampermonkey) 파일로 다운로드

    Tampermonkey 없이 이 버튼을 누르면 코드가 텍스트로 보이기만 합니다. 순서를 지켜주세요.

  3. 확인

    기존 스크립트를 v4.2.2으로 교체하고 게임 탭을 새로고침하세요. 여러 버전을 동시에 켜지 마세요.
    커서를 목표에 멈추면 결론과 이유, 다음 행동이 표시됩니다. 재분석 중에는 직전 결과를 유지하고 아래에 갱신 상태만 표시합니다. 커서를 옮긴 경우 이전 결과에는 이전 위치라고 표시합니다. 비용·방향·배치 근거는 F8에서 확인하세요.
    I를 한 번 누르면 해당 위치를 고정하여 다시 검증하고 추천 계획을 실행합니다. 수소 혼합이 검증되면 우선 선택하고, 그렇지 않으면 검증된 원자 집중 계획을 사용합니다.
    Esc는 계산과 남은 발사를 취소합니다. 이미 발사한 미사일은 취소되지 않습니다.
    F8로 사일로와 SAM의 좌표·레벨·준비 수량을 확인합니다. 상세가 길면 표시창 안에서 스크롤하세요.
    발사 중 SAM이 강화되면 남은 발사를 보류하고 다시 계산합니다. 가능하면 원자탄으로 수소탄을 보완하고, 수소 보완이 안 되면 원자 집중으로 전환합니다. 대응 계획이 없으면 중단하고 재장전·사일로 레벨업 후보 등을 안내합니다.
    기본 목표는 수소 1발 또는 원자 1발 도달입니다. 이번 공격 전체 한도는 원자 2,000발·수소 1발이며 재계산해도 누적됩니다. 계산 미완료는 불가능 판정이 아닙니다.
    X + 클릭은 일반 구조물 +500 = 10건, 사일로 +300 = 6건입니다. 같은 구조물의 작업 중 중복 클릭을 막고 Esc로 남은 업그레이드를 취소합니다.
    N → 바다 클릭은 클릭마다 군함 10척을 대기열에 추가합니다. 연속 클릭은 위치를 저장해 순서대로 건조하며, 한도가 차면 기다립니다. Esc로 남은 대기열을 취소합니다.
    기존 수동 기능 H / G / J / M / Z / V / X / N은 유지됩니다. 추천 계획 실행 중에는 다른 단축키 공격이 차단됩니다.

Tampermonkey 없이 쓰기 (콘솔에 붙여넣기)

openfront.io 게임 화면에서 F12 → Console 탭 → 아래 버튼으로 복사 → 붙여넣고 Enter.

탭을 새로고침하면 다시 붙여넣어야 합니다. 계속 쓰려면 Tampermonkey 설치를 권장합니다.

예측은 적의 추가 건설·다른 플레이어의 명령·통신 지연을 보장하지 않습니다. 재계산에는 이번 공격에서 발사 반영을 확인한 미사일만 사용합니다. 다른 미사일의 SAM 소모와 폭발로 인한 SAM 파괴는 성공 조건에 포함하지 않습니다. 레벨업 안내는 다음 공격의 시험 후보이며 최소 레벨·업그레이드 비용 보장은 아닙니다.
