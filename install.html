OpenFront x50 스크립트 설치

v2.7.0 · I: 수소타격 한큐 — 목표를 커버하는 모든 SAM을 분석해 필요 원자+랜덤 5~50발을 쏘고, 사각창에 수소 1발을 꽂은 뒤 원자 수십발·수소 몇발을 랜덤 간격으로 산개 — 발사 전 궤적·SAM 충전·방어량을 전부 계산해 첫 수소가 들어갈 때만 발동 · Z: 1,000발 살포 (연타 = 대기열) · 화면 모서리 HUD: 서버 리밋 해제 카운트다운(80%) + 커서 타깃 필요 원자·비용·사일로 상시 표시  +  원자 50발 / xMax / 수소 / MIRV  +  구조물 +50 (V) / +500 (X) 업그레이드
사설·연습 로비 전용

  1. Tampermonkey 설치 (먼저!)

    크롬 웹스토어에서 Chrome에 추가 → 확장 프로그램 추가 를 누르세요.

    Tampermonkey 설치 페이지 열기

    설치 후 한 번 더: chrome://extensions → Tampermonkey → 세부정보 → 사용자 스크립트 허용 켜기
    (이걸 빼먹으면 스크립트가 작동하지 않습니다)

  2. 스크립트 설치

    Tampermonkey가 설치된 뒤에 아래 버튼을 누르면 Tampermonkey 설치 화면이 뜹니다 → 설치 클릭.

    스크립트 설치 (Tampermonkey) 파일로 다운로드

    Tampermonkey 없이 이 버튼을 누르면 코드가 텍스트로 보이기만 합니다. 순서를 지켜주세요.

  3. 확인

    openfront.io 에 접속 → F12 → 콘솔에 [x50] 준비 완료 가 뜨면 성공.
    게임에서 V 한 번 → 무장 유지 → 구조물을 계속 클릭 (클릭마다 +50 누적, 사일로는 +30)
    X → 같은 방식으로 +500씩 (사일로는 +300) — 클릭하면 즉시(서버 초당 한도인 500레벨을 한 번에 요청, 1초대). 해제는 X/Esc
    N 누르고 바다 클릭 → 군함 10척 한 번에 건조 (항구 필요)
    M → 커서 위치에 MIRV (탄두 최대 350발, 영토에만) — 누르고 있으면 연사
    I → 수소타격 한큐: 목표를 커버하는 적 SAM(사거리·레벨)을 전부 분석해 필요 원자만큼 전량 발사 → 회복 사각창에 수소 1발 → 3~5% 추가 벌크를 한 번에. SAM이 없으면 일반 살포와 동일. (화면 모서리 HUD가 필요 원자·비용·사일로를 상시 표시)
    Z → 커서 위치에 원자폭탄 1,000발을 서버 최대 속력(초당 500발)으로 살포 (약 1.2초). 연달아 누르면 누른 위치별로 대기열에 쌓여 끊김 없이 이어서 나감 (5곳 연타 = 5,000발 연속). 자동 중단: 골드 소진·발사관 소진 시 낭비 없이 멈춤 (Esc로 수동 중단도 가능). 서버 분당 한도 도달 시 남은 초만큼 대기 후 자동 재개
    키를 누르고 있으면 서버 감당 속도로 자동 반복 발사 (H/G/J/M) / H 원자 50발 / G xMax / J 수소 1발 / M MIRV (탄두 350발)

Tampermonkey 없이 쓰기 (콘솔에 붙여넣기)

openfront.io 게임 화면에서 F12 → Console 탭 → 아래 버튼으로 복사 → 붙여넣고 Enter.

탭을 새로고침하면 다시 붙여넣어야 합니다. 계속 쓰려면 Tampermonkey 설치를 권장합니다.

설치가 끝나면 이 페이지와 로컬 서버는 더 이상 필요하지 않습니다.
